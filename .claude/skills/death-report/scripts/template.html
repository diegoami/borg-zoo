Play one yourself

  

    
On your machine, ~/borg-play/__PACK__ has an X11 build of the same commit and four saves per death. Each death has an exact replay, --to,: the Borg replays from birth (checked against the zoo's keys) and hands you the window. Loading a save and pressing Ctrl-Z starts a new Borg with empty memory, so it plays a different game.

    
cd ~/borg-play/__PACK__ && ./play.sh __FIRSTDIR__ --to 1400

    
cd ~/borg-play/__PACK__ && ./play.sh __FIRSTDIR__

    
The commands follow the death selected above. Each death is also a borg-cemetery dossier (link in the header of each death).
