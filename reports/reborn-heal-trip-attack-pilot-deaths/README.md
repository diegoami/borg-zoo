## Replay

Build the pinned specimen and run the arm with the logs kept (the zoo holds the shared lock for heavy local runs, RULES 9):

```sh
flock /tmp/angband-validation.lock python3 -m zoo build --specimen 4.2.6-reborn-rust-heal --source CHECKOUT_AT_PIN --out build
flock /tmp/angband-validation.lock python3 -m zoo run --experiment experiments/reborn-heal-trip-attack-pilot.json --specimen 4.2.6-reborn-rust-heal \
    --arm 4.2.6-reborn-rust-heal:reborn-heal1-trip1-attack1-plan --build build --work work --out out --jobs 4 --keep
```
