# The named scary monsters (borg-reborn-rs #518), read when borg.txt sets
# borg_scary_list = <this file> and caution_scary_named_monsters = 1.
#
# A known monster on the level makes it scary (the Borg leaves and flees)
# while the character's level is at most the monster's level for its class.
#
# Each monster has a range, tough - fragile: the level up to which the
# toughest class (fragility 0) and the most fragile one (fragility 100) fear
# it. A class in between fears it up to
#     tough + (fragile - tough) x fragility / 100, rounded.
# Fang at 5-8: Warrior, Paladin, Blackguard 5; Ranger, Rogue 6; Priest,
# Druid 7; Mage, Necromancer 8 (owner, 2026-11-17).
#
# One line per monster:
#   monster | scary up to clevel: tough - fragile | class exceptions | flags
# - monster: the race name exactly as in monster.txt, or base:<start of a
#   monster base name> (base:ancient dragon matches every ancient dragon).
# - a single number instead of a range is the same level for every class.
# - class exceptions: "class level" pairs, comma-separated, giving that
#   class's level for this monster outright (0 = scary only at level 0,
#   i.e. never in play).
# - flags: "breeders" = only while at least as many breeders as the
#   character's level are known, and not while the Borg stands and fights
#   breeders (#503).
#
# A later line for the same monster replaces the earlier one, and
# "monster | none" removes it; a later fragility value replaces an earlier
# one. An experiment can append its own lines to this file instead of
# editing it (borg-zoo#228).
#
# An unknown monster, class or flag, a bad number or a backwards range stops
# the run before play. To remove a monster, delete or comment out its line.

# Class fragility, 0 (toughest) to 100 (most fragile).
fragility: warrior 0, paladin 0, blackguard 0, ranger 33, rogue 33, priest 67, druid 67, mage 100, necromancer 100
